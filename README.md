# Customer Shopping Behavior Analysis

##  Overview
This project is an end-to-end **Data Analytics** project that analyzes customer shopping behavior using transactional data. The objective is to uncover customer purchasing patterns, product preferences, revenue trends, and subscription behavior through data analysis and visualization.

The project follows a complete analytics workflow, including **data preprocessing in Python**, **business analysis using SQL**, and **interactive dashboard creation in Power BI**.

---

##  Dataset
The dataset contains customer shopping transactions with **3,900 records** and **18 features**, including:

- Customer ID
- Age
- Gender
- Category
- Item Purchased
- Purchase Amount
- Location
- Subscription Status
- Shipping Type
- Discount Applied
- Review Rating
- Previous Purchases
- Season
- Size
- Color
- Purchase Frequency

##  Project Workflow

### 1. Data Loading
- Imported dataset into Jupyter Notebook
- Explored data structure
- Checked data types and summary statistics

### 2. Data Cleaning & Preprocessing
- Handled missing values
- Renamed columns for consistency
- Removed redundant columns
- Created new features (Age Group, Purchase Frequency)
- Performed data validation and consistency checks

### 3. Exploratory Data Analysis (EDA)
- Customer demographics analysis
- Revenue analysis
- Product category analysis
- Subscription analysis
- Review rating analysis

### 4. SQL Analysis
Solved multiple business problems using SQL, including:

- Revenue by Gender
- High-Spending Discount Users
- Top Rated Products
- Shipping Type Comparison
- Subscriber vs Non-Subscriber Analysis
- Discount-Based Product Analysis
- Customer Segmentation
- Top Products by Category
- Repeat Buyer Analysis
- Revenue by Age Group

### 5. Dashboard Development
Created an interactive **Power BI Dashboard** featuring:

- KPI Cards
- Revenue Analysis
- Customer Distribution
- Sales by Category
- Revenue by Age Group
- Subscription Analysis
- Interactive Filters & Slicers

### 6. Documentation & Presentation
- Prepared a detailed project report
- Created a presentation using **Gamma**

##  How to Run

### Python
1. Clone this repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run all cells for preprocessing and EDA.

### SQL
1. Import the cleaned dataset into SQL Server/PostgreSQL/MySQL.
2. Execute the SQL queries provided.

### Power BI
1. Connect Power BI to the SQL database.
2. Load the dataset.
3. Open the Power BI report (.pbix) to explore the dashboard.
